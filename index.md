This guide sets up your computer for **MIS 58710 DevOps and Technology Solutions**. Completing it is **Prep 2 – Setup** (ungraded but required). GP 1.2 assumes you've finished it.

## What you'll have at the end

- A **Linux command line**: Ubuntu through WSL on Windows, Terminal on a Mac, or Cloud Shell in your browser
- **Git**, configured with your name and email
- The **GitHub CLI (`gh`)**, signed in to your GitHub account
- **Python 3.11 or newer** and **Poetry 2**, the tool we use to manage Python projects
- **VS Code** with the extensions the course uses (or the Cloud Shell Editor)
- The **Google Cloud CLI (`gcloud`)**, signed in to your Google account
- A screenshot from the verification script showing that everything works

## How long it takes

| Path | Typical time |
| --- | --- |
| Windows (WSL) | 60–90 minutes, including a restart |
| Mac | 45–60 minutes |
| GCP Cloud Shell | 20–30 minutes |

Most of that time is spent waiting for downloads. Start early, and don't start right before class.

## How to use this guide

1. Read [](why-linux.md) (two minutes).
2. Use [](choose-your-path.md) to pick **one** part: Windows, Mac, or Cloud Shell.
3. Follow that part from top to bottom. Each step gives you a command to copy and one line on what it does.
4. Finish with [](verify.md) and submit the screenshot.
5. Stop at [](stop-here.md). Later chapters are opened when the course needs them.

:::{tip} Copying commands
Hover over any code block and click the copy button in its top-right corner. Paste it into your terminal and press **Enter**.
:::

## Getting help

If you get stuck, check [](troubleshooting.md) first. If that doesn't help, contact the instructor or TA.

Include in your message:

- which part you're following (Windows, Mac, or Cloud Shell)
- the step you're on
- the command you ran and the **full error message** (copy the text, or take a screenshot)
