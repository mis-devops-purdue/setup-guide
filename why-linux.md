---
title: Why Linux?
---

**Linux is the backbone of DevOps.** Most of the software you'll build and run in this course ends up on Linux:

- **Servers.** Most web servers and cloud virtual machines run Linux.
- **Containers.** Containers are packaged Linux environments.
- **CI runners.** The machines that test and build code automatically are almost always Linux.
- **Cloud Run.** When you deploy an app to Google Cloud Run later in the course, it runs on Linux.

If you work in a Linux command line from day one, the commands you practice on your laptop are the same ones that run in the cloud. That's why:

- **Windows** students install **WSL** (Windows Subsystem for Linux), which runs a real Ubuntu Linux inside Windows.
- **Mac** students use the built-in Terminal. macOS isn't Linux, but it is Unix-based, so nearly all the commands are the same.
- **Cloud Shell** *is* a Linux machine, running in Google's cloud and opened in your browser.

You don't need any Linux experience to start. This guide gives you every command.
