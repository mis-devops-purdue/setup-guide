title: 4. The Cloud Shell Editor
---

The **Cloud Shell Editor** is your editor in Part 3. It's built on Code OSS, the open-source code behind VS Code, so most of what you'll see in class looks the same.

## Step 1: Open the Editor

If the Editor isn't showing, click **Open Editor** in the terminal toolbar.

## Step 2: Open your projects folder

Click **File → Open Folder**, choose `projects` inside your home folder, and click **OK**.

<!-- SCREENSHOT: Cloud Shell Editor "Open Folder" dialog with the projects folder selected -->

## Step 3: Find your way around

- **Explorer** (top icon on the left) shows your files.
- **Terminal → New Terminal** opens a terminal inside the Editor.
- **Extensions** (the icon of four squares on the left) shows installed extensions.

## Step 4: Confirm Python support

Click **Extensions** and look in the **Installed** section for **Python**. Cloud Shell includes Python support, so you don't need to install anything.

<!-- SCREENSHOT: Cloud Shell Editor Extensions view showing the Python extension under Installed -->

:::{note} Extensions in Cloud Shell
The Cloud Shell Editor gets extensions from **Open VSX**, an open marketplace, not from Microsoft's VS Code Marketplace. You don't need to install the extensions listed in Parts 1 and 2. If **Python** isn't listed under Installed, search the Extensions view for `Python` and install it.
:::
